# **Glossar**

:::{note}
Auf dieser seite definiere ich Begriffe rund um CommonMark, GFM und das
Executable Book Ökosystem.
:::

---

- **Markdown**
ist eine Sprache zur Formatierung von Klartext, die von John Gruber in 2004 entwickelt wurde.


- **CommonMark**
ist eine präzise und  eindeutige Spezifikation von Markdown. Es ist das Fundament für GFM, MyST und das gesamte Executable Book Ökosystem.

- **GFM (GitHub-Flavored Markdown)** ist der Markdown von GitHub. Eine erweiterung vonCommonMark um Tabellen, Task-Listen, Durchstreichensfunktion und Syntax

- **Jupyter Book**
ist ein Werkzeug zum Erstellen von  Bücher und Websites aus Markdown-Dateien

- **Task-Liste**
ist eine GFM-Erweiterung für Checklisten oder To-Do Listen
